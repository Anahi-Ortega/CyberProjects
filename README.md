# Cyber Labs 🛡️

A structured portfolio of my **security labs, CTF write-ups and professional-format reports**, documenting my path into cybersecurity across multiple training platforms.

It serves two purposes: a **learning journal** (what I practiced and what I learned) and a **demonstration of skills** in vulnerability analysis, penetration testing and security operations.

## 🔹 Types of Documentation

The repo separates *how I learned* from *what I can deliver*:

- 📘 **Walkthroughs** document the steps of a lab or challenge, including dead ends and lessons learned. They live with their platform.
- 📝 **Notes** are study references on concepts and tooling. They live with their platform.
- 📄 **Reports** present results the way a client or security team would expect to receive them. They all live in [`Reports/`](./Reports) and link back to their source walkthrough.

| Report type | Describes | Example |
|---|---|---|
| **Finding report** | One vulnerability: evidence, root cause, impact, remediation, detection | PortSwigger lab findings *(in progress)* |
| **Engagement report** | A full assessment for an executive audience | Mr. Robot: 1 |
| **Incident report** | One investigated security alert | SOC Simulator: Introduction to Phishing |

See the [Reports index](./Reports/README.md) for the full list, naming conventions and report structures.
